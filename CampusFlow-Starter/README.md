# CampusFlow

Smart Student Task & Campus Management Platform.

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MySQL
- API: REST
- Version control: Git + GitHub

## MVP
1. User registration/login
2. Dashboard
3. Task management
4. Deadlines/events
5. Projects and team members
6. Smart task priority

## Project structure
- frontend/ - React application
- backend/ - Express REST API
- database/ - MySQL schema
- docs/ - project documentation

## Run
### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Configure MySQL using `database/schema.sql` and copy `backend/.env.example` to `backend/.env`.

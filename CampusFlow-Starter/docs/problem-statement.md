# CampusFlow — Problem Statement

## Problem
College students manage assignments, deadlines, events, project work and team communication through scattered tools such as messaging apps, notebooks and separate calendars. This fragmentation can make it difficult to prioritize work and coordinate group projects.

## Proposed Solution
CampusFlow is a centralized student productivity and campus-management platform that combines tasks, deadlines, projects, team coordination, events and notifications in one responsive web application.

## MVP
- Dashboard
- Task management
- Deadline tracking
- Projects and team members
- Events
- Smart priority
- Notifications

## Future Add-ons
- Study planner
- Time-management module
- Campus event management
- Analytics
- Additional student productivity tools
